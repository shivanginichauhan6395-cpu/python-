MCA101P - Lab Sheet 09
Python Programming Lab: CRUD Operations

This folder contains 20 beginner-friendly Python programs based on the supplied lab sheet.

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in VS Code or any Python editor.
3. Open Terminal in this folder.
4. Run a program using:
   python 01_create_student_list.py
   (Replace the filename with the program you want to run.)

DATABASE PROGRAMS (11-20)
- These programs use SQLite, which is included with most Python 3 installations.
- They create/use a database file named student.db in the same folder.
- Run 11_create_students_table.py first, then run the other database programs.
- Program 12 or 20 can be used to add records before testing view/search/update/delete.

FILE PROGRAMS
- Programs 9 and 10 create their text files in the folder from which they are run.

NOTE
- Programs 1-8 use sample/in-memory data where suitable. Their data resets when the program is closed.
- Change the sample names or values if your teacher asks you to use your own test data.
