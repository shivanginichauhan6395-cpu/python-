# MCA101P Python Programming Lab Solutions

Answers for Lab Sheets 01–06. Every question is in its own Python file (`Q01_...py`, `Q02_...py`, etc.), grouped by lab sheet.

## Run a program
```bash
python Q01_add_two_integers.py
```
Run the command from the relevant lab-sheet folder. Each program asks for input where appropriate.

## Upload to GitHub
1. Create a new repository on GitHub.
2. Extract this ZIP file on your computer.
3. Open the extracted folder and check the six lab-sheet folders.
4. On GitHub, choose **Add file → Upload files**, drag the folders and `README.md` into the page, then commit the changes.

Please run and review each program in Python before submitting it for assessment.
