# MCA101P Python Programming Lab Solutions

Answers for Lab Sheets 01–08. Every question is in its own Python file, grouped by lab sheet.

## Run a program
```bash
python Q01_add_two_integers.py
```
Run the command from the relevant lab-sheet folder. Each program asks for input where appropriate.

For Lab Sheet 07 (file handling), run a program from its folder, for example:
```bash
python 01_write_file.py
```

For Lab Sheet 08 (database management), run a program from its folder, for example:
```bash
python 01_connect_database.py
```

The lab-sheet folders and their Python files are available directly in this repository.

Please run and review each program in Python before submitting it for assessment.
